# 과제 제출 방법

---

과제 제출은 레포지토리 포크가 아닌, 하나의 레포지토리를 가지고 여러 명이 협업하는 **공동 작업** 방식으로 진행됩니다.  

1. 팀장이 설정한 공통 저장소를 로컬 컴퓨터로 복제합니다.
    
    ```bash
    git clone 레포지토리주소.git
    ```

2. 본인의 이름으로 브랜치를 생성한 후, 작업 위치를 생성한 브랜치로 변경합니다.
    
    ```bash
    git checkout [본인 브랜치명] (이미 존재하는 브랜치로 이동)
    git checkout -b [본인 브랜치명] (브랜치를 새로 생성하고 바로 이동)
    ```
    
3. 본인의 이름으로 생성된 패키지로 파일 위치를 이동하여 과제 코드를 작성합니다.
4.  작성을 완료하였다면 원격 브랜치로 업로드합니다. 
    - 원격 브랜치에 업로드하는 방법
        - **원격 브랜치에 업로드하기 전, 최신 main의 상태를 내 로컬에 반영하여 팀원이 작성한 코드를 덮어쓰지 않도록 주의합시다. (3, 4 참고)**
        
        ```bash
        1. git add .
        2. git commit -m “커밋 메시지”
        3. git fetch origin
        4. git pull origin main 
        5. git push origin [본인 브랜치명]
        ```
        
5. 깃허브 웹으로 이동하여 Pull Request를 생성하고 main 브랜치로 merge합니다.

- **한 팀원당 최소 3번 PR이 필수입니다.**
